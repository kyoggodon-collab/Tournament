# 研究室対抗ソフトボール大会 トーナメント表

2会場（A: ソフトボール場 / B: 多目的広場）で、会場間移動を最小にした組み合わせを自動生成するブラウザアプリです。

## 使い方

```bash
npm install
npm test
npm run build
npm start
```

開発時（API `3001` + Vite `5173`）:

```bash
npm run dev
```

ブラウザで開く URL:

| 役割 | URL | できること |
| --- | --- | --- |
| 閲覧者 | `/` | 試合時刻、会場、スコア、勝ち上がり、順位 |
| ルール | `/rules` | 大会注意事項 |
| 運営 | `/admin` | 共通パスワード後にチーム編集・生成・スコア記録 |

初期パスワードは `r8softball` です。運営画面の設定タブで変更できます。環境変数 `ADMIN_PASSWORD` は初回起動時の初期値に使います。

データは `data/tournament.json` に保存されます。

## 組み合わせの考え方

- チーム数は 2〜32。半数を会場A、半数を会場Bに固定する。
- 各会場で単淘汰を完結させる。予選中は会場を移動しない。
- 優勝決定戦のみ B会場勝者が A会場へ移動する（閉会式もA）。
- 3位決定戦のみ A会場準優勝が B会場へ移動する。
- 本戦のイニング・制限時間は大会ルールに合わせ、決勝枠は60分。
- 審判は原則負け審。同じ時間帯に試合があるチームは割り当てない。

## スコア

同点はルールどおりじゃんけんで勝者を指定します。先の試合の勝者変更は、以降の試合結果を取り消します。
